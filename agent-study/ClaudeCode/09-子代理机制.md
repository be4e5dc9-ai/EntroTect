# Claude Code 子代理机制（AgentTool = 递归调用同一个 query()）

> 归属：`agent-study/ClaudeCode/` | 关键词：AgentTool、createSubagentContext、sidechain、coordinator、fork、run_in_background
> 核心文件：`src/tools/AgentTool/`（AgentTool.tsx、runAgent.ts）、`src/constants/tools.ts`

---

## 1. 核心实现：递归 query()

子代理不是新进程、不是新框架——**就是过滤了工具池的又一次 query() 调用**：

```ts
// tools/AgentTool/runAgent.ts:700-757（精简）
const agentCtx = createSubagentContext(toolUseContext, {
  options: filteredTools,          // 过滤后的工具池
  agentId, agentType,
  messages: initialMessages,       // 只有 task prompt，不带父历史
  abortController: agentAbortController,
  shareSetAppState: !isAsync })    // 同步共享父 store；异步隔离

for await (const msg of query({
    messages: initialMessages,
    systemPrompt: agentSystemPrompt,   // 轻量提示词（见 05）
    canUseTool,
    toolUseContext: agentCtx,
    maxTurns })) {
  await recordSidechainTranscript([msg], agentId)   // 写 sidechain 文件
  yield msg                                          // 进度流回父循环 UI
}
```

**这是性价比最高的扩展点**：复用主循环全部能力（权限、压缩、持久化），只换工具池与系统提示词。

## 2. 输入 schema（AgentTool.tsx:82-102）

```ts
{ description,        // 给父模型看的一句话（何时该派我）
  prompt,             // 完整任务指令
  subagent_type,      // 代理类型
  model?,             // 可指定便宜模型
  run_in_background?, // 后台运行
  isolation?: 'worktree' }  // git worktree 隔离
```

## 3. 内置代理类型与自定义

- 内置：general-purpose / Explore / Plan / verification / statusline-setup；
- 自定义：`.claude/agents/*.md` frontmatter 定义（name/description/tools/model + body 即 system prompt）。

## 4. 工具隔离与递归防护

- `ALL_AGENT_DISALLOWED_TOOLS`：外部发行版禁 Agent 工具本身 → **防无限递归派生**；
- `ASYNC_AGENT_ALLOWED_TOOLS` 白名单（constants/tools.ts:36-88）：后台代理只能用白名单内工具；
- finally 块精确清理子代理的 MCP server 连接并 kill 其后台 shell，防僵尸进程。

## 5. Coordinator 模式（env 开启）

开启后主 Claude 只剩 **4 个工具**：Agent / TaskStop / SendMessage / SyntheticOutput（constants/tools.ts:107）——彻底退化为调度器，worker 在独立进程跑完整工具集。这是"编排者-执行者"分离的极端形态。

## 6. Fork 变体

不带 subagent_type 即 fork 自己：

- 后台运行、继承当前完整历史；
- 冻结共享父 prompt cache（`renderedSystemPrompt`，Tool.ts:293）——fork 出的分支读同一份缓存前缀。

用途："把我现在的上下文复制一份去并行试另一个方案"。

## 7. 后台任务框架（src/tasks/）

| 来源 | 行为 |
|---|---|
| Bash 超时 | 自动转后台任务 |
| Agent run_in_background | 立即返回任务 id |
| RemoteAgentTask | 云端派发 |

统一由 TaskOutput / TaskStop 读写状态；完成时以附件形式注入父会话。

## 8. 自研启示

1. 子代理 = createSubagentContext(过滤工具池) + 递归调用同一 loop。不要写第二个循环。
2. 防递归：子代理工具池里删掉 Agent 工具。
3. transcript 物理隔离（sidechain），父 resume 不背子历史。
4. 结果回传只取最后 assistant 文本即可满足绝大多数场景。
