## 1. Tool 接口定义（src/Tool.ts:362-695）

```ts
export type Tool<Input extends AnyObject, Output, P> = {
  name; aliases?: string[]
  inputSchema: Input                       // ★ Zod 是唯一事实来源
  inputJSONSchema?: ToolInputJSONSchema    // MCP 工具可直传 JSON Schema（逃生舱）
  call(args: z.infer<Input>, context, canUseTool, parentMessage, onProgress?)
    : Promise<ToolResult<Output>>
  prompt(options): Promise<string>         // 给模型的描述——动态函数而非静态字符串
  checkPermissions(input, ctx): Promise<PermissionResult>
  validateInput?(input, ctx): Promise<ValidationResult>   // call 前的语义校验
  isConcurrencySafe(input): boolean        // 该组参数下能否与其他工具并行
  isReadOnly(input): boolean
  isEnabled(): boolean                     // feature gate
  maxResultSizeChars: number               // 结果超限自动落盘换预览；Infinity=自管(如 Read)
  shouldDefer?: boolean                    // 配合 ToolSearch 延迟下发 schema
  mapToolResultToToolResultBlockParam(content, toolUseID): ToolResultBlockParam
  renderToolUseMessage / renderToolResultMessage / renderToolUseErrorMessage  // Ink UI 三渲染器
}

export type ToolResult<T> = {
  data: T
  newMessages?: Message[]          // 工具可注入额外消息（如 TodoWrite 更新）
  contextModifier?: (ctx) => ...   // 有序副作用：修改 toolUseContext
  mcpMeta?
}  // :321
```

### 工厂 buildTool 的 fail-closed 默认值（Tool.ts:757/783）

| 字段 | 缺省 | 理由 |
|---|---|---|
| isConcurrencySafe | **false** | 忘记声明的工具宁可串行 |
| isReadOnly | **false** | 宁可多走权限审批 |
| checkPermissions | allow | 只读工具免审 |

## 4. Schema 定义范式：Zod strictObject + describe

```ts
// src/tools/BashTool/BashTool.tsx:227-259
z.strictObject({
  command: z.string().describe('...'),
  timeout: semanticNumber(z.number().optional()).describe('...'),  // 上限同步告知模型
  run_in_background: ..., dangerouslyDisableSandbox?: ...
})
// 内部字段 _simulatedSedEdit 从模型可见 schema 中 omit（sed -i 审批机制，见 06-权限）
```

要点：
- `z.strictObject` 拒绝多余字段——模型幻觉出的参数直接被 safeParse 拦截并回喂修复提示；
- 每个 describe 都写给模型看，等价于微型文档；
- 内部实现用的字段（如 `_simulatedSedEdit`）用 omit 从 wire schema 隐藏，执行时再剥离。

## 5. Zod → API Schema 序列化（utils/api.ts:119-266 toolToAPISchema）

每次请求时把 Zod 转 JSON Schema 并组装：

```
zodToJsonSchema(inputSchema)            // 或直传 inputJSONSchema（MCP）
+ description = await tool.prompt()     // 动态描述（可引用当前环境状态）
+ 会话级按名字缓存                       // ★ 防止同一工具每轮生成不同 schema 打爆 prompt cache
+ 可选叠加：strict / eager_input_streaming / defer_loading / cache_control
```

兼容开关：`CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` 在这个唯一出口剥离所有非标字段，保证严格代理网关可用。

## 6. 自研启示

1. 工具接口的最小集 = `name + inputSchema + call + prompt + checkPermissions + mapToolResultToToolResultBlockParam`；其余都是渐进增强。
2. **prompt() 是函数不是常量**——工具描述可随会话状态变化（如 task 工具动态列出可用子代理）。
3. fail-closed 三默认（不并行/非只读/要审批）是安全底线。
4. schema 必须缓存：同一工具的 JSON Schema 字节级稳定是 prompt cache 命中的前提。
