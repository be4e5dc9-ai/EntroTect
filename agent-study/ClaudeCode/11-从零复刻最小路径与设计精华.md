# Claude Code 从零复刻最小路径（10 步）与设计精华

> 归属：`agent-study/ClaudeCode/` | 关键词：最小可行 agent、实施顺序、里程碑

---

## 0. 核心心法（一句话）

> **Agent = 一个 while(true) 的异步生成器，把「模型输出中的 tool_use」翻译成「本地副作用」，再把副作用结果翻译回「user 消息里的 tool_result」；其余一切——权限、压缩、持久化、子代理、UI——都是围绕这个翻译器的可靠性工程。**

## 2. 设计精华速查（写给未来的自己）

1. 循环出口看 **tool_use 数量**，不看 stop_reason。
2. Zod 是 schema 唯一事实来源；工具描述 prompt() 是动态函数。
3. fail-closed 三默认：新工具默认不并行、非只读、要审批。
4. prompt cache 是一等公民：静态/动态分界符、built-in 工具连续前缀、user-context prepend 通道、schema 会话级缓存、request-id 链路分析——一切为了字节稳定的前缀。
5. 截断三道闸（50k 落盘 / 200k 聚合 / Read 25k-token 自限）+ 六层压缩阶梯。
6. 权限 deny 回喂理由让模型自纠换路。
7. 错误分类驱动恢复：413→压缩；截断→提额+"Resume directly…"≤3 次；模型故障→fallback+补孤儿 tool_result。
8. 错误扣留：恢复管线跑完前不给用户看红字。
9. 子代理 = 过滤上下文 + 同一个 loop，不要写第二个循环。
10. UI 只是主循环的消费者——先把 query() 写成纯库函数。
