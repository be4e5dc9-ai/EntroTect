> 归属：`agent-study/deepseek-harness/` | 关键词：分阶段路线、三条纪律、独特设计

## 1. 独特设计 Top 10（相对其他 agent 的差异点）

1. **"Model-visible ⟺ logged" 不变量**（architecture.md L96）：任何将进入模型上下文的字节必须可从日志重建；编译器+运行时双重强制——新模型可见输入必须新增 SessionEventMap 成员。
2. **SurfaceOp replace**：append-only 日志上的可逆压缩（磁盘无损、审计可展开）。
3. **Capability Seam 三角色律**：Service Definition / Provider / Consumer 三者齐备才算缝（architecture.md L98-104）；换 provider 整链迁移（本地→E2B 远程演示）。
4. **Waterfall 即唯一扩展哲学**："Plugins, not loop changes"——pre-step / request / request-error / pre-execute / execute / post-execute / system-prompt/assemble / llm/stream 全是 around-middleware。
5. **工具管线防御纵深**：塌缩判定先于策略管线；单调 guard（顺序无法翻案 deny）；wrapper 可换 signal 但 caller signal 熔合回归；结果三次快照冻结。
6. **取消语义完备性**：ABORTED vs ABORTED_BEFORE_DISPATCH 二分；abort 写合成配对结果保证重放有效；wake latch 处理竞态。
7. **KV-cache 感知压缩**：摘要复用会话前缀避免失效缓存；request/header 快照使断线重连后仍命中 provider 前缀缓存。
8. **Code Mode 同谓词**：模型被告知的规则与注册表强制的规则出自同一函数 collapses()。
9. **Fail-loud 配置文化**：restrict({}) 报错、prompt 变量缺失抛错、misconfiguration fails loud at load。
10. **品牌化 id**（util/brand Branded<B>）：SessionId/CallId/WorkflowRunId 跨边界裸 string 编译失败。

## 3. 贯穿全程的三条纪律

1. 任何进入模型上下文的字节必须可从日志重建；
2. 所有跨边界 id 品牌化、所有持久化数据 lossless-JSON+冻结；
3. 扩展行为优先加事件/瀑布监听器，不改循环本体。
