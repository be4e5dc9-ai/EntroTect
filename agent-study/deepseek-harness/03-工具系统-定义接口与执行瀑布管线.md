## 1. ToolDefinition 接口（index.ts:221-288）

```ts
export interface ToolDefinition extends ToolSchema {   // ToolSchema={name,description,parameters(JSON Schema)}
  readonly output: ToolOutputDefinition                // 强制：canonical 输出声明
  execute(args: unknown, exec: ToolRunContext): Promise<unknown>  // 只返回 canonical lossless-JSON
  finalizeContent?(exec, result): ContentBlock[]       // 最后一公里内容变换（恰好一次）
  timeoutMs?: number                                   // 协作超时预算；绝不发给模型 ★
  isConcurrencySafe?(args): boolean                    // 仅精确 true 才允许并行；异常一律独占
  presentCall?(args): ToolCallView                     // 纯函数：UI pending 态卡片
  presentResult?(args, result): ToolResultView         // 纯函数：完成态卡片（重放期也会调用）
}
export interface ToolOutputDefinition {
  readonly schema: JsonSchemaNode                      // 对成功值强制校验
  render(args, value): ContentBlock[]                  // 纯投影：canonical 值 → 模型可见内容
  presentationMeta?(args, value): JsonValue            // 可重放展示载荷
}
```

三个教学级约束：

1. **execute 只许返回结构化 canonical 值**——registry 负责 JSON Schema 校验 + `output.render` 投影 + 冻结（createSuccessResult L1793-1823，违反抛 INVALID_TOOL_OUTPUT）。工具不直接拼"给模型看的文本"，文本是 canonical 数据的纯投影。
2. **UI 渲染意图是设计的一部分**：presentCall/presentResult 必须是 args/result 的纯函数，因为崩溃重放期间也要调用它们复原界面。
3. **timeoutMs 永不出现在 wire schema**：schemas() 白名单只有 name/description/parameters（L1256-1267）。

## 2. 执行管线：五段瀑布（registry execute() L1342 起）

```
① createExecution(L1364)
     参数做 lossless-JSON 快照并 deepFreeze；
     Code Mode 塌缩判定在此短路：模型直呼非 run_code → UNKNOWN_TOOL(L1423-1444)
     —— 发生在策略管线之前："listeners must never observe a call that can only fail"
② tools/pre-execute waterfall (L1473-1481)
     决策 allow | deny(reason) | ask(reason?)
③ serviceAsk（审批缝裁决 L1689-1729）
     ask → ctx.get('approval') 审批缝；无审批缝/无 agent 一律降级 deny（fail-closed）
④ guards 单调守卫（L704-711, L1119-1128）
     只能追加否认理由；任何 guard 否认即拒；listener 顺序无法把 deny 翻回 allow
⑤ tools/execute around-waterfall
     超时/重试/指标包装器；wrapper 可换 exec.signal 但注册表把 caller signal
     熔合回去（fuseToolSignals L1889-1916）——取消不可剥离 ★
⑥ tool body 执行
     bodyInvoked 标记；成功值走 createSuccessResult 校验/渲染/冻结
⑦ tools/post-execute waterfall (L1742-1781)
     accept（可换 content/value）| block（纠错反馈变 isError）；都可附加
     additionalContexts 给下一请求
⑧ materializeFinalResult（L1847-1862）
     再快照再冻结 → Object.freeze(exec) → emit tools/result
```

## 3. 失败物化与规范错误码

失败统一为判别联合（L556-580）：

```ts
{ isError: true, error: { message, info?: { name, code } }, content }
{ isError: false, value, content, meta?, additionalContexts?, concludesTurn? }
```

- 取消按 body 是否已启动二分：`ABORTED` / `ABORTED_BEFORE_DISPATCH`（L469-472）；
- 未知工具抛 ToolNotFoundError（code `UNKNOWN_TOOL`，L494-510），与工具自身错误一样可路由；
- `concludesTurn` 允许某工具提前结束整个 turn。

## 4. 作用域化：全局注册 / agent 影子 / restrict

`register/restrict/guard/presentAs` 都可在 `agent.ctx`（scoped context）调用：

- scoped 同名注册**遮蔽**全局；
- `restrict({allow/deny})` 过滤的是继承面且跨链相交，但**不过滤本层自己的注册**——view() 注释（L1152-1193）解释：delegation runtime 要往 child 层塞 report 工具，不能被 child 自己的能力过滤器剥掉；
- 重复全局注册报错并教正确做法（L726-728）："for a per-agent variant, register through that agent's agent.ctx instead"；
- `restrict({})` 空过滤器直接报错（L1078-1080）："这几乎总是物化成空的配置 bug"。

## 5. 自研启示

1. 工具返回结构化数据 + render 投影 = 同一份结果可同时服务模型文本、UI 卡片、日志重放。
2. 管线分段（pre/execute/post waterfall）让超时、重试、审批全部成为外挂中间件。
3. 单调守卫 + fail-closed 审批降级是权限系统不被顺序漏洞击穿的关键。
